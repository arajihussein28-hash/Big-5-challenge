a pixel lesson in counting work

BIG-O QUEST

Five small challenges. Each one teaches a growth rate by counting real steps.

Choose a door

    How to play

    1. Pick a door. Each door is one algorithm with its own growth rate.
    2. In Learn mode, press Start and watch the character work. Pause, press Next step, or change the speed.
    3. In Challenge mode, the work pauses at each decision. Click the right chest, room, or coin, or choose the left or right crystal.
    4. The counter counts real operations: array reads, checks, comparisons, writes, and swaps. Wrong clicks are counted as mistakes, not as operations.
    5. After a run, press Try a bigger n to double the input and compare how the work grew.

    One operation:

    Each box has an index under it in brackets, like [8]. The number inside is the value stored there. items[8] means the value at index 8. Do not confuse the two.
